隐私政策

保护用户通信隐私与数据安全是万达云的核心立足之本。

1. 严苛的“零活动日志”承诺 (No-Logs Policy)

万达云在此郑重声明并承诺：本平台所有专线服务器均配置为 RAM 纯内存无盘运行机制，严禁且技术上杜绝记录任何用户的具体网络活动数据。

具体而言，我们绝不记录、绝不存储、绝不追踪、绝不分发以下任何个人行为信息：

  • 您所浏览的任何目标网站域名、网页 URL 与 API 请求路径；
  • 您在通信过程中上传或下载的任何数据报文内容与明细；
  • 您的源 IP 地址与每次连接的目标 IP 地址映射记录；
  • DNS 查询历史解析记录（全局采用自建内存加密 DNS 解析，查询完毕即刻销毁）。

2. 所收集之必要基础账户信息

为了保障账号体系的正常运维与订阅续期，我们仅收集最基础且必要的账户信息：

  • 注册时提交的电子邮箱地址（作为唯一身份认证标识）；
  • 密码采用行业高标准 Argon2id 单向加盐哈希算法加密，即使内部系统管理员亦无法逆向解密；
  • 仅用于流量统计与计费的周期总吞吐量数值（不含任何访问行为上下文）。

3. 传输层加密与安全保障

万达云在物理专线中全面启用 AEAD（ChaCha20-Poly1305 / AES-256-GCM）前向安全加密传输标准。所有流经光纤信道的数据均被深度加密，有效杜绝任何网络监听、流量劫持或中间人攻击风险。

4. 政策更新与咨询通道

若隐私政策发生任何重要修订，我们将在官网显著位置发布公告。如有关于隐私安全或数据处理之任何疑问，欢迎随时通过工单系统联系万达云技术安全合规团队。
